# TAKEN 自動防衛・自動食事

## 有効にする

起動中のBotをCtrl+Cで終了して終了を待ち、C:\mc-server\AI\aibot-realms\RealmsAI起動.bat を起動し直してください。起動時は自動食事と自動防衛の両方がオンです。再起動で個別のオン・オフと停止状態は初期設定に戻ります。

| コマンド | 動作 |
|---|---|
| !TAKEN 自動行動状態 | 自動行動の停止状態と個別設定を表示 |
| !TAKEN 自動行動オン | 全体の停止を解除 |
| !TAKEN 自動行動オフ | 全体を停止 |
| !TAKEN 自動食事オン / !TAKEN 自動食事オフ | 食事の個別設定 |
| !TAKEN 自動防衛オン / !TAKEN 自動防衛オフ | 防衛の個別設定 |
| !stop / !TAKEN 止まって | 作業と自動行動を停止 |
| !TAKEN 状態 | 体力・満腹度・自動行動の状態を表示 |

全体が停止中の場合、個別設定をオンにするだけでは再開しません。!TAKEN 自動行動オン を使ってください。操作権限はこれまで通りMC_OWNERSの設定に従います。

## 自動食事

満腹度16以下、または体力8以下かつ満腹度20未満で食べます。ホットバーのパン・焼いた肉など、既存の安全な食料一覧から選びます。食事前後の満腹度を確認します。食料がない、満腹度の増加を確認できない場合は中止し、10秒程度空けて再確認します。自動調理と持ち物の並べ替えは未対応です。

## 自動防衛

Bot本人の体力が減った直後（4秒以内）、3.1ブロック以内の見通しのある指定敵へ近接攻撃します。ゾンビ・スケルトン等が対象です。ホットバーに剣・斧があれば選び、なければ現在の持ち物で攻撃します。1回ごとに距離・体力・対象・見通しを確認し、1秒ごとの監視で必要なら再実行します。

プレイヤー・村人・ペット・家畜・エンダーマン・クリーパーは自動攻撃しません。体力8以下では攻撃しません。追跡・逃走・盾・弓は未対応です。近くの敵を選ぶ方式であり、攻撃者の特定や討伐を保証するものではありません。

## 作業との関係

自動行動と手動作業を同時に実行しません。通常の自動食事は作業の終了を待ちます。被ダメージ直後に近接敵がいる、満腹度6以下、体力8以下で食事が必要、という緊急時には作業を中止し、自動行動へ切り替えます。中止した作業は自動で再開せず、もう一度指示が必要です。

食事中に近接敵からの危険が検出された場合は食事を中止し、防衛を再確認します。死亡・復活処理・切断でも自動行動を中止します。

## ゲーム内で確認する

1. ホットバーにパン等と剣を用意し、!TAKEN 持ち物 と !TAKEN 自動行動状態 を確認します。
2. 安全な場所で満腹度が減った際に、食べる動作と !TAKEN 状態 の満腹度増加を確認します。
3. 防衛はまず単体のゾンビ等で、体力と停止指示を確認できる環境で試してください。安全な復活地点を用意します。
4. !stop の後に自動行動が停止し、!TAKEN 自動行動オン で再開するか確認します。

今回の追加機能は模擬クライアントで検証済みです。自動行動の排他、停止・再開、死亡、対象除外、見通し、手動作業中の緊急中止を含む全42件のテストが通りました。Realms上の追加機能は未検証です。
